This folder holds optional generic STAR-CCM+ 2402 Java macros (*.java) that are not tied to one project, for example a residual-plot formatter or a mesh-statistics printer; SimKit's "Run a library macro" tool lists every *.java file found here, together with lib\projects\<PROJ>\ and the case macros\ folder, and plays the selected file in the open simulation. Each file must be a complete, self-contained macro (a public class with the same name as the file, extending star.common.StarMacro, with no dependency on SimKit.java), it must follow the SimKit rules (never delete objects, write files only into the case folder, wrap uncertain API calls in try/catch), and its FIRST LINE must be a one-line comment describing what it does, for example "// Print the cell count and the minimum cell quality of every region", because SimKit shows that line as the macro's description in the menu list. The folder is read-only for users; send new or changed macros to the toolkit owner.
